# MemQL website (archived)

This repository is archived. It was the source of memql.io until
2026-09-15, and it is no longer built or deployed.

- **The site** is memql.io. Its source now lives in `clients/memql-website`
  in the private instance repository that hosts memql.io.
- **The documentation** memql.io serves is written in the engine repository,
  [znasllc-io/memql](https://github.com/znasllc-io/memql), under `docs/public`,
  and published with every engine release as `docs-<version>.tgz`.
- **Issues** about the site or its docs belong in
  [znasllc-io/memql](https://github.com/znasllc-io/memql/issues).

The Cloud Run deploy workflow was removed when the repository was archived.
